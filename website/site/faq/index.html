What is Intellimatrix?

Intellimatrix is Amit Pandey’s independent collection of software tools and experiments at the intersection of AI, data, and development. Meet the builder.

What can I use today?

Onboarder is an open-source public beta for exploring codebases. Q3 is a research prototype. Start with Onboarder or visit the Q3 workspace.

Is Onboarder free?

Onboarder is available under the MIT License. Optional model providers may charge separately for AI services. Supporting the creator through Buy Me a Coffee is voluntary.

Can this website scan my repository?

The map on the Onboarder product page is an illustrative example. Install Onboarder to analyze a repository on your own machine; the marketing sites do not accept repository uploads.

Does my code leave my machine?

Core analysis is local. Loading a Git URL contacts the Git host. Optional AI sends task context and requested source to your configured provider. See the documentation and our privacy explanation.

Do I need an account or an API key?

No website account is required. Onboarder’s offline exploration does not require an AI account or API key. Optional AI review and fix proposals use a compatible endpoint or a separately installed Hermes agent with your configured provider.

How do I report a bug or contribute?

Read the documentation, then use GitHub issues for reproducible bugs and product feedback. Use email for private reports. Do not put credentials or private source in public issues.

How do I change or clear my theme?

Use the theme button in the header. Your choice is shared by cookie between the sites. The Cookies page explains storage and includes a reset control.

Where can I ask for accessibility help?

The sites support keyboard navigation, light/dark mode, and reduced-motion preferences. If something is difficult to use, contact Amit with the page, device, and the issue so it can be investigated.

Does a coffee contribution buy support or future features?

Coffee contributions help support independent development. They do not create a subscription, guaranteed support response, or promise of future features. See the Terms of Use for more information.
