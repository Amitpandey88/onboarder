A FEW PRACTICAL DETAILS

Before you install.

Is Onboarder free?

Yes. It’s open source under the MIT license. Optional model providers may charge separately for AI services.

Does my code leave my machine?

Core maps, offline exploration, and local reviews run on your machine. Optional AI sends context and requested source to your configured provider. Loading a Git URL contacts the Git host.

Do I need an AI account?

No, not for repository analysis or offline exploration. Optional AI workflows require Hermes and a configured provider.

Can I scan my repository on this page?

This page includes an illustrative interactive map. Install Onboarder to analyze your own repository locally with the terminal explorer or web workspace.

How can I contribute?

Visit the GitHub repository to read the source, report an issue, or submit a pull request. Beta feedback helps shape the next release.
