# Onboarder showcase film

A 40-second, 1920 × 1080, 30 fps motion graphic for Onboarder 1.0.2.
The finished MP4 uses H.264 video, stereo AAC audio, and a fast-start header.

The art direction follows the product's warm paper, dark ink, forest accents,
serif typography, and amber terminal. The film combines eased reveals, drawn
connection paths, drifting compass orbits, gently rotating product panels,
camera push-ins, soft shadows, slow dissolves, and a typed install command.
An original synthesized ambient soundtrack includes soft transition sweeps.
There is no voice-over, paid inference, downloaded stock footage, or stock music.

Screens come from this project's real interface. The Review image is a local
report captured during the 1.0.2 development work; the crop shows its report
content rather than the older navigation order. Review counts are examples
from that scan, not live repository statistics. The terminal was captured
from an installed 1.0.2 terminal session and has no configured AI model.
Graphic lines outside the UI are editorial illustrations of connections.

## Files

- `onboarder-showcase.mp4`: finished video.
- `poster.jpg`: cover frame.
- `storyboard.jpg`: six-scene contact sheet.
- `preview-01.jpg` through `preview-06.jpg`: full-size scene frames.
- `ambient-original.wav`: original soundtrack source.
- `render.py` and `assets/`: editable, deterministic source and product captures.

GitHub contains a smaller 1080p share copy, the poster, storyboard, renderer,
and input assets. The full-quality master is retained locally under `master/`.
The WAV and individual preview frames are generated by the renderer and omitted
from Git to keep the upload compact.

## Render again

Install Pillow and NumPy in a Python environment and install FFmpeg.
On macOS the renderer uses Georgia, Avenir Next, and Menlo; Linux uses DejaVu
fallback fonts. No dependencies are added to the Onboarder npm package.

```sh
python render.py --preview
python render.py --render
```

The video and its editable assets are published in this GitHub repository.
The product release remains version 1.0.2.
