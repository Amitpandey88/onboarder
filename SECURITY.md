# Security reports

Report suspected vulnerabilities privately through [GitHub private vulnerability reporting](https://github.com/Amitpandey88/onboarder/security/advisories/new). If that feature is unavailable, use the repository owner's GitHub contact options; do not publish secrets or working exploits in public issues.

Security fixes target the current release and development branch. Older versions are not maintained separately. Include the affected version, platform, reproduction steps and expected impact. Keep tokens, private code and personal data out of reports unless the maintainer explicitly arranges a secure transfer.

See [Supply-chain security](docs/SUPPLY_CHAIN_SECURITY.md) for external tool trust boundaries and release verification.
