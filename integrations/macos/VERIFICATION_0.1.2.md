# Glass controls and responsiveness — 0.1.2, verified 2026-10-28

The user reported that the full-window glass interface was laggy and unusable.
This update replaces that implementation and keeps the paper/ink workspace.
Local development only; no publication, deployment or account writes.

## Implementation

- Removed the Objective-C++ glass bridge, its native binary, and the AppKit
  `contentView` replacement. The Electron window stays opaque throughout its
  lifetime. Editor, diagrams, file tree, sidebars, dialogs and home cards retain
  solid backgrounds.
- **Liquid Glass buttons** now controls a lightweight CSS finish on exactly five
  toolbar buttons: Home, UI settings, Search, Terminal and New project. Inset
  highlights, restrained borders and a warm surface provide the finish, without
  backdrop sampling, native materials, blur, gradients or animated transforms.
  The existing opt-in preference carries forward. This is a glass-style finish,
  not AppKit's Clear/Tinted material. macOS accessibility preferences still take
  priority; the finish is available from macOS 14.
- Removed button hover displacement and decorative entrance/drag scaling.
  Graph overlays use solid surfaces, and map focus uses opacity without blurring
  SVG nodes. Focus outlines, active states, tooltips and the opening spinner remain.
- Panel dragging coalesces pointer changes once per animation frame and saves
  the final size on release, cancellation or lost capture. Keyboard resizing
  retains arrow-key operation and saves on release/blur.
- Preference reads and window focus no longer reapply materials or broadcast
  unchanged settings. Actual preference/system changes update affected windows.
- Fixed toolbar tooltips disappearing when unrelated map/editor panels scroll.
  Position updates are batched per frame; hover/focus text remains readable.

This follows Apple's recommendation to keep glass in a distinct functional layer
and avoid overuse: [Materials](https://developer.apple.com/design/human-interface-guidelines/materials),
[Adopting Liquid Glass](https://developer.apple.com/documentation/TechnologyOverviews/adopting-liquid-glass).
The approach also reduces unnecessary UI-thread work described in
[Electron's performance guidance](https://www.electronjs.org/docs/latest/tutorial/performance).

## Checks

- Compared the original 0.1.1 native window effect, opaque mode, a scoped button
  backdrop blur and a scoped static finish on the same 320-file fixture. All had
  renderer frame p95 around 17.6ms; the short renderer test did not reproduce the
  user's native-compositor lag. The static finish was selected to remove the
  full-window native hierarchy change and background-sampling work entirely.
  No claim of a measured percentage speedup is made.
- The revised 2,000-file source workspace measured frame p95 17.7ms with controls
  enabled (17.6ms opaque), zero frames over 50ms and zero observed long tasks
  during scrolling. Filtering returned in 18ms with the finish enabled. These are
  local fixture measurements, not guarantees for every repository/device.
- A 128-event pointer burst produced one layout update and one preference save.
  Eight preference reads produced zero appearance broadcasts. Actual Monaco
  editing, selected control styling, opaque workspace backgrounds and stable
  hover targets were checked through the application.
- Core full check: 1,046 passed, zero failures, one optional Compiler API skip;
  474 generated outputs, 99 vendor assets and 840 package files verified; zero
  architecture violations. All 13 focused desktop tests pass.
- Browser and packaged application checks, performance receipts, source
  comparisons and screenshots are kept in ignored `dist/qa/`.
- Final packaged 2,000-file check on 2026-10-28: glass controls frame p95 16.7ms,
  zero frames over 50ms, zero observed scrolling long tasks, 19ms filtering;
  the same one-layout/one-save resizing and zero redundant preference broadcasts.
  All 14 packaged views pass with the finish enabled, including the actual
  TypeScript worker, chat/shell terminals, Unicode, bundled Node on restricted
  PATH and isolated project windows; zero page errors. Backend isolation, real
  Git clone safety and process cleanup pass. Browser's 14 views, 390px layout,
  hover/focus text and all 22 diagram/security renders pass without overflow or
  page errors. Core, vendor, diagram-build and desktop audits have zero advisories.
- Final source verification: 850 packaged-source comparisons, zero mismatches.
  DMG/ZIP SHA-256, internal archive integrity and deep/strict ad-hoc signatures
  pass. No native glass binary is shipped.
